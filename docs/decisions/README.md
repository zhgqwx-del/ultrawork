# Architecture Decision Records (ADR)

本目录记录 Ultrawork 项目中的关键架构决策。每个 ADR 描述一个重要的技术选择、其背景、考虑过的替代方案和后果。

## 格式

每个 ADR 遵循统一模板：

```markdown
# ADR-NNN: 标题

**状态**: Accepted | Superseded | Deprecated
**日期**: YYYY-MM-DD
**关联轮次**: Round N / Phase N

## 背景
为什么需要做这个决策？

## 决策
选择了什么方案？

## 考虑过的替代方案
还考虑过哪些方案？为什么没选？

## 后果
这个决策带来了哪些影响（正面和负面）？
```
