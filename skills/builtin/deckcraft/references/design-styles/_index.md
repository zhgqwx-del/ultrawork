# 风格库索引（选定一个后只读那一个明细文件，禁止 glob 全目录）

所有风格文件**不含 HEX**——只写气质、排版纪律与用色行为；具体色值在 spec_lock 阶段按「色彩推导协议」（spec-lock-format.md）产出。

| id | 气质一句话 | 适用场景 | 深浅 |
|---|---|---|---|
| `swiss-minimal` | 冷静克制的瑞士网格：白底、强层级、单强调色 | 商务汇报、策略提案、董事会材料 | 浅 |
| `editorial-warm` | 暖纸编辑部：杂志排版的沉稳与人文感 | 复盘报告、案例分享、品牌叙事 | 浅 |
| `tech-dark` | 深色科技：高对比、数据感、克制的锐利 | 产品发布、技术分享、数据汇报 | 深 |
| `academic-calm` | 学术沉稳：衬线标题、规矩层级、论证优先 | 学术演讲、研究汇报、培训课件 | 浅 |

## 自动推荐规则（question 设计确认前先给推荐项）

| 信号 | 推荐 |
|---|---|
| 汇报对象是管理层/客户、诉求「专业」 | swiss-minimal |
| 内容偏故事/复盘/人文，或用户说「有温度」 | editorial-warm |
| 主题是产品/技术/数据，或用户说「酷/现代」 | tech-dark |
| 学术/教学/研究语境 | academic-calm |

拿不准时默认推荐 swiss-minimal（最不会错），并在候选里给出另外 2 个。
