# 现行规格

按能力将已交付的行为放在 `specs/<capability>/spec.md`。新增或改动先在 `changes/<id>/spec.md` 评审，随实现和验收证据将实际交付的规则同步到这里。

从[规范模板](../docs/stdd/templates/spec.md)开始。关联需求与场景 ID，便于定位测试和受测版本。

| 能力 | 现行规格 |
| --- | --- |
| 桌面启动 | [启动就绪与阻断](desktop-startup/spec.md) |

项目功能全览见 [Ultrawork 产品需求](../docs/requirements.md)。现行规格随已验收的变更逐步补齐。
