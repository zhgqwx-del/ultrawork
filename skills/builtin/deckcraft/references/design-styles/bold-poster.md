# bold-poster — 海报式冲击

**气质**：像一张海报而不是一页幻灯片。信息少、字大、色块实。

## 用色行为（HEX 在 spec_lock 产出，这里只定行为）
- 底色高明度纯色（近白或极浅有彩色），不用灰调
- 主色一个：高饱和实色，**用作 `data-dark` 页的整页底**（满幅色块由此实现），不是点缀
- 次级底 `--c-bg2` 是主色的**极浅染色档**，不是饱和块——卡片上的 `--c-head`/`--c-muted` 要能读
- 强调色一个：主色的对比色，只出现在一处——多了就成了色彩噪音
- **大面积实色底上的文字必须走 --c-on-dark 档**，别用正文墨色硬压

- **高饱和主色做 `data-dark` 页底时，禁止用 `opacity` 压暗 on-dark 文字**（脚注/meta 也不行）：实测白字 55% 透明压在高饱和橙上只有 **2.21:1**，掉出对比度下界。要弱化就**缩字号**，不要降透明度。

## 排版纪律
- 标题占据页面 1/3 以上高度；正文极少，一页 ≤2 句
- 字重只用两档：display 700 与正文 300，中间档一律不用
- 色块边缘齐版心，不留半格——海报的力量来自边界干脆

## Do / Don't
- Do：满幅色块、超大字、单一焦点、齐边界
- Don't：多焦点、细密正文、渐变、投影、圆角

## CJK 适配
- 中文超大字需更重字重才压得住（display 用 700，思源黑 Heavy 更佳）
- 标题 ≤8 字；中文方块字在 display 尺寸下极占面积

## 骨相 token（写进 tokens.css §Structure；值即本风格的"骨"）

| 变量 | 值 | 为什么是它 |
|---|---|---|
| --sl-pad | 48px | 48px 让色块更贴边，海报感来自满 |
| --bar-w / --bar-h | 120px / 12px | 120×12 粗实色条——**招牌**，是缩小版的色块语言 |
| --kicker-transform / --kicker-spacing | uppercase / .2em |  |
| --fw-head / --fw-sub / --fw-body | 700 / 500 / 300 |  |
| --lh-body | 1.5 | 1.5 收紧，正文本来就少 |
| --measure | 30em | 30em 窄栏，逼迫文案精简 |
| --radius / --rule-w | 0 / 1px |  |

推荐字体配对：`humanist-display`（见 typography-cjk.md §字体配对）

> **Allowances**：本风格不放开任何全局禁项。

## Signature（非可选）

`data-signature="slab-block"` —— **120×12 的粗实色条 + 满幅实色块**。
条一细、块一留白边，整张就从海报退回普通幻灯片。全 deck 色块齐版心、条宽统一。
