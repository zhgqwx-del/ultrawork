# paper-craft — 纸质手作

**气质**：像一本手工装订的小册子。不追求精致，追求亲切。

## 用色行为（HEX 在 spec_lock 产出，这里只定行为）
- 底色米黄/浅麻（暖且低明度差），次级底再深一档做"贴纸"
- 主色一个：墨色偏暖（深褐/墨绿），像印在纸上的油墨
- 强调色一个：朱砂/靛蓝一族——传统印章色，只给标签与编号
- 整体饱和度低；纸的质感靠明度层次而非纹理图（本 skill 无图纹）

## 排版纪律
- 标签用实心小色块 + 反白文字（"盖章"效果），不用边框
- 编号手写感来自字重轻 + 字号大，不是字体（无手写字体可依赖）
- 行距宽、字号偏小——像书页不像投影

## Do / Don't
- Do：暖纸底、盖章标签、宽行距、朴素排布
- Don't：冷色、高饱和、锐利细线、科技感网格

## CJK 适配
- 全衬线（宋体族）最贴合纸质感；正文 300-400
- 标签文字用黑体 500 反白，与衬线正文形成材质对比

## 骨相 token（写进 tokens.css §Structure；值即本风格的"骨"）

| 变量 | 值 | 为什么是它 |
|---|---|---|
| --sl-pad | 72px | 72px 像书页的天头地脚 |
| --bar-w / --bar-h | 40px / 16px | 40×16 近方形色块——**招牌**，是"印章"而不是"线" |
| --kicker-transform / --kicker-spacing | none / normal |  |
| --fw-head / --fw-sub / --fw-body | 700 / 500 / 300 |  |
| --lh-body | 1.85 | 1.85 书页式宽行距 |
| --measure | 34em |  |
| --radius / --rule-w | 0 / 2px |  |

推荐字体配对：`serif-full`（见 typography-cjk.md §字体配对）

> **Allowances**：本风格可放开 `shadow`（spec_lock 写 `<!-- deckcraft:allow shadow -->`，并写明理由）。

## Signature（非可选）

`data-signature="stamp-tag"` —— **40×16 的近方形印章块 + 暖纸底**。
块一变细长就成了普通 accent bar，纸一变冷就成了普通浅色 deck。
