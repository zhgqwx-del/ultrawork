本目录存放随产品分发的法律文本草稿。本轮以某同类桌面云产品的公开协议为**结构参考**，但**实质条款按本产品真实形态（本地优先 + BYOK 直连第三方、无第一方数据收集后端）重写**，而非逐字替换品牌名——因为参考文档是**云服务**协议，其中大量"我们收集你上传的数据 / 云电脑账号 / 第三方支付 / 埋点 SDK"等条款与本产品不符，照抄会构成**虚假陈述**。

## ⚠️ 使用前必读

1. **这是草稿，不是生效协议**。正式商业售卖前必须由**执业律师/法务**审阅并定稿，尤其是 AI 输出免责、数据跨境、责任上限、消费者权益（《消费者权益保护法》《电子商务法》）等条款。
2. **占位符必须全部替换**（见下表），否则协议无效。
3. **主体必须真实**：当前主体状态＝**尚未注册公司**。协议的签约方、开票方、担责方、管辖法院都依赖一个**真实已注册的经营主体**。以个人名义商用会显著放大个人责任，且无法开具增值税发票——强烈建议注册公司后再正式发布。
4. **数据形态若变化必须同步更新**：当前为"本地优先 + BYOK"，隐私政策据此撰写。**一旦引入自建后端服务（收集账号/上传内容/日志/遥测），隐私政策与服务协议都必须重写并重新征得用户同意**——两份草稿已各留一条前向兼容条款提示此点。

## 占位符替换清单（全局统一替换）

| 占位符 | 含义 | 示例 | 决定什么 |
|--------|------|------|---------|
| `【产品名】` | 对外商用产品名称 | UltraWork / … | 全文所有产品名字眼 |
| `【公司主体】` | 责任/签约主体全称 | XX科技有限公司 | 签约方、担责方、开票方 |
| `【公司注册地址】` | 主体注册地址 | XX省XX市XX区XX路X号 | 送达、管辖 |
| `【管辖法院】` | 争议管辖法院 | XX市XX区人民法院 | 诉讼管辖（通常为主体所在地） |
| `【官网】` | 官方网站 | https://ultrawork.ai | 通知、公告、下载 |
| `【客服邮箱】` | 客服/支持邮箱 | support@example.com | 用户联系 |
| `【个人信息保护负责人邮箱】` | DPO/隐私投诉邮箱 | privacy@example.com | 隐私请求 |
| `【生效日期】` | 协议生效日期 | 2026年X月X日 | 版本、生效 |
| `【适用地区法律】` | 适用法律辖区 | 中华人民共和国大陆地区 | 法律适用 |

> 建议：定稿时用一次全局查找替换处理占位符，替换后通读一遍确认没有云服务残留字眼（如"云电脑""上传至服务器""实名认证"等与本产品形态不符的措辞）。
