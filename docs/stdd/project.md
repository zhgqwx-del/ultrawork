# Ultrawork STDD/SDD 项目入口

## 项目目标

Ultrawork 提供桌面 AI Agent 工作环境。用户可在本地工作区与 OpenCode 或外部 Agent 会话，通过 Team 或流水线协同执行任务，并接入消息渠道与知识源。

| --- | --- |
| 产品定位、功能范围和实现状态 | [产品需求](../requirements.md) |
| 交互设计与原型 | [功能清单](../../design/product/feature-checklist.md) · [桌面原型](../../design/product/prototype/README.md) |
| 系统分层和接口 | [架构](../architecture-phase1.md) · [OpenCode API](../api-reference.md) |
| 已交付行为和对应验收场景 | [现行规格索引](../../specs/README.md) |

| 讨论与长期决策 | [讨论索引](../discussions/README.md) · [ADR 索引](../decisions/README.md) |
