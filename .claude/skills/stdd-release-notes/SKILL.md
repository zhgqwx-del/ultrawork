# 版本差异与发布说明

1. 从任务或发布记录定位起止引用，解析并固定双方 SHA。要求远端最新时刷新已确认的引用，失败则标明本地快照。版本比较用 `python3 -B scripts/git_range.py <基准引用> <候选引用>`，文件差异取两端快照；按日期汇总时采用项目迭代日历和主线合入记录，注明分支、时间窗、时区及统计截止时刻，不把作者日期直接当作合入日期。
2. 同时核对提交列表和文件差异，再对照变更记录、规格及验收证据。分叉或回退版本可能没有候选独有提交却存在快照差异，不能因此宣称无变化。将同一功能合并为可观察条目，按项目领域分类，核对新增、修复、撤回、依赖和兼容变化；筛选或排除的范围需写明，避免重复计数或遗漏。
3. 依据 `docs/stdd/templates/release.md` 起草说明，注明范围、用户影响、兼容与迁移、验收状态和待处理项。候选说明与已发布状态分别记录，实际发布引用对应记录。沿用项目变更日志或片段约定；只要求分析时直接给出报告，保存文件按任务范围执行，发布操作使用项目另行接入的流程及授权。
