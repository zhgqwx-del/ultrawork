# mono-terminal — 终端绿

**气质**：像一块显示器而不是一份文档。克制到只剩结构与光。

## 用色行为（HEX 在 spec_lock 产出，这里只定行为）
- 底色近黑（带一点冷色温，避免纯黑死感）
- **单色荧光**：主色与强调色同一色相（绿/琥珀/青任选其一），靠明度分层
- on-dark 文字用荧光色的低饱和高明度版本，不用纯白
- muted 是荧光色压暗档——**不要用中性灰**，灰会破坏单色系统

## 排版纪律
- **全等宽**：标题与正文同族，层级只靠字号与明度
- kicker 用 `> ` 或 `$ ` 式提示符前缀（写在文案里，不是装饰元素）
- 数字与代码天然对齐——tabular-nums 必开

## Do / Don't
- Do：单色明度阶梯、细网格线、提示符前缀、大段留白
- Don't：多色相、衬线、圆角、任何拟物装饰

## CJK 适配
- 等宽族不含 CJK，汉字必然穿透到黑体——这是预期，等宽性格由西文与数字承担
- 深底上中文字重不低于 400，荧光色细字会发虚

## 骨相 token（写进 tokens.css §Structure；值即本风格的"骨"）

| 变量 | 值 | 为什么是它 |
|---|---|---|
| --sl-pad | 56px | 56px 略紧，屏幕感 |
| --bar-w / --bar-h | 24px / 8px | 24×8 方块——像一个光标 |
| --kicker-transform / --kicker-spacing | none / .05em |  |
| --fw-head / --fw-sub / --fw-body | 700 / 500 / 400 |  |
| --lh-body | 1.6 |  |
| --measure | 34em |  |
| --radius / --rule-w | 0 / 1px |  |

推荐字体配对：`mono-display`（见 typography-cjk.md §字体配对）

> **Allowances**：本风格不放开任何全局禁项。

## Signature（非可选）

`data-signature="caret-rule"` —— **24×8 的方块光标 + 单色荧光明度阶梯**。
换成多色或加了中性灰，就只是一份深色 deck，不是终端。
