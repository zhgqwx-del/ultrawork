# ADR-015: 深色模式 + CodeMirror 6
**状态**: Accepted
**日期**: 2026-03-09
**关联轮次**: Round 15

## 背景

深色模式下各组件背景色不统一（sidebar 和主区域色差明显）。产物预览使用简单的 pre/code 标签，无语法高亮和代码功能。

## 决策

1. **深色模式统一纯黑 #000000**（sidebar-bg + color-bg）。
2. **引入 CodeMirror 6** 替代纯文本预览，支持语法高亮、行号、代码折叠，集成 17 个语言包。

## 考虑过的替代方案

1. **深灰色背景 (#1a1a1a)** — 更柔和但与设计稿不符。
2. **Monaco Editor** — 功能更强但体积大（~5MB），桌面场景不需要编辑功能。
3. **Prism.js / highlight.js** — 只有高亮无行号/折叠。

## 后果

- **正面**: 深色模式视觉统一、代码预览专业级体验、CodeMirror 按需加载语言包。
- **负面**: 17 个语言包增加 bundle 大小、CodeMirror 主题需要与 Tailwind CSS 变量手动对齐。
