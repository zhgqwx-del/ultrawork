# tech-dark — 深色科技

**气质**：高对比、数据感、克制的锐利。深色是底色不是特效。

## 用色行为
- 底色深冷（近黑的蓝灰/石墨，避免纯黑 #000 一族的死黑感——在 spec_lock 里选深而有色温的值）
- 次级底比底色亮半档，做分区；on-dark 文字用暖白（不是纯白）
- 主色即底色家族；强调色一个：高饱和亮色（电青/亮橙/荧绿一族选一），只点数字与关键词
- **深色页反转规则**：本风格 --c-bg 即深色，浅色页（若需要）反而是节奏变化页

## 排版纪律
- 对比即层级：亮度差替代色相差；大数字（--fs-num）是本风格的招牌元素
- 细线（1-2px、低透明度）做结构分隔，网格感可以比 swiss 更露骨
- 等宽/tabular 数字必开；kicker 全大写字距拉开

## Do / Don't
- Do：大数字、亮色点睛、细网格线、暗底亮字的克制对比
- Don't：霓虹渐变、发光效果（glow/shadow）、彩色堆叠、深色底配纯黑文字区块

## CJK 适配
- 黑体族；深底上中文字重不低于 300+（过细会发虚），正文可用 400 档（spec_lock ramp 里明确）
- 深底上 muted 色要亮过浅底方案，否则辅助信息不可读

## 骨相 token（写进 tokens.css §Structure；值即本风格的"骨"）

| 变量 | 值 | 为什么是它 |
|---|---|---|
| --sl-pad | 64px | 标准版心 |
| --bar-w / --bar-h | 32px / 6px | bar 收到最短——深底上的锐利来自克制 |
| --kicker-transform / --kicker-spacing | uppercase / .3em | 字距比瑞士系统更开，是本风格的口音 |
| --fw-head / --fw-sub / --fw-body | 700 / 500 / **400** | **深底上 300 会发虚**，正文必须走 400 档 |
| --lh-body | 1.55 | 收紧行距做数据感 |
| --measure | 32em | 窄栏 + 大数字的对比是本风格的骨架 |
| --radius / --rule-w | 0 / 1px | 细线做结构分隔，网格感可比瑞士更露骨 |

> **深浅反转（本风格独有，务必逐条照做）**：`--c-bg` 与 `--c-primary` 深 ⇒
> `--c-head` / `--c-text` / `--c-muted` **全部为浅色**。`--c-primary` 只当 `data-dark` 页底
> 与结构元素，**绝不当墨色**——深字压深底近乎隐形（ADR-068 D8）。

## Signature（非可选）

`data-signature="mono-caps"` —— **等宽标题族 + 32×6 短促 bar + .3em 全大写 kicker**。
三者共同构成"终端感"；只换深色底而不动这三处，得到的只是一份被调暗的瑞士 deck。
汉字必然穿透到黑体（等宽族不含 CJK），这是预期行为——等宽性格由西文与数字承担。
