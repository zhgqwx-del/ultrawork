# 风格库索引（选定一个后只读那一个明细文件，禁止 glob 全目录）

所有风格文件**不含 HEX**——只写气质、排版纪律、用色行为与**骨相 token**；具体色值在 spec_lock 阶段按「色彩推导协议」（spec-lock-format.md）产出。

| id | 温度 | 气质一句话 | 适用场景 | 深浅 |
|---|---|---|---|---|
| `swiss-minimal` | 中性 | 冷静克制的瑞士网格：白底、强层级、单强调色 | 商务汇报、策略提案、董事会材料 | 浅 |
| `editorial-warm` | 安静 | 暖纸编辑部：杂志排版的沉稳与人文感 | 复盘报告、案例分享、品牌叙事 | 浅 |
| `tech-dark` | 中性 | 深色科技：高对比、数据感、克制的锐利 | 产品发布、技术分享、数据汇报 | 深 |
| `academic-calm` | 安静 | 学术沉稳：衬线标题、规矩层级、论证优先 | 学术演讲、研究汇报、培训课件 | 浅 |
| `bold-poster` | 大胆 | 海报式冲击：超大字 + 实心色块，一页一句话 | 发布预告、活动海报、内部动员、社媒长图 | 浅 |
| `duotone-vivid` | 大胆 | 双色撞击：两个高饱和色平分页面，几何切分 | 年轻向品牌、社媒、活动预热、创意提案 | 浅 |
| `noir-luxe` | 大胆 | 黑金：深底 + 衬线大标题 + 一线金属色 | 品牌发布、高端产品、年度盛典、投资人材料 | 深 |
| `mono-terminal` | 大胆 | 终端绿：全等宽、单色荧光、命令行秩序感 | 技术分享、开发者活动、CLI/基础设施主题 | 深 |
| `blueprint-tech` | 中性 | 蓝图：深蓝底 + 细网格 + 等宽标注 | 架构方案、技术评审、系统设计、工程汇报 | 深 |
| `paper-craft` | 安静 | 纸质手作：米黄纸底、盖章式标签、朴素亲切 | 工作坊、教育材料、手册、公益/文化项目 | 浅 |

> **温度**（安静 / 中性 / 大胆）不是质量评价，是**表达强度**。模型对"安静极简"有确定性偏好——
> 候选集若全是安静档，就等于没给选择。`pick_variants.py` 会强制候选跨 ≥2 个温度档。

## 候选怎么来：**先跑脚本，不要自己挑**

```bash
python3 ${SKILL_DIR}/scripts/pick_variants.py .deckcraft/<name> --topic "<主题>"
```

脚本按 `项目名|主题` 的确定性 hash 打乱候选顺序并写 `variants.json`（含 seed，可复现可回放）。
**Phase 3 的 question 必须按 `variants.json` 里 `styles` 的顺序呈现候选。**

- **不要固定选第一个**，也不要跳过脚本凭印象挑——顺序已经被打乱过了，你的"印象"只会把它拉回默认。
- 下面这张表是**给用户看的解释**（哪个信号对应哪个风格），不是给你用来直接定选项的清单。
- 用户明确点名某个风格时以用户为准，脚本结果作废。

| 信号 | 对应风格 |
|---|---|
| 汇报对象是管理层/客户、诉求「专业」 | swiss-minimal |
| 内容偏故事/复盘/人文，或用户说「有温度」 | editorial-warm |
| 主题是产品/技术/数据，或用户说「酷/现代」 | tech-dark · blueprint-tech |
| 学术/教学/研究语境 | academic-calm |
| 用户说「要有冲击力/抓眼球」、页少字大 | bold-poster · duotone-vivid |
| 品牌发布、高端感、投资人材料 | noir-luxe |
| 开发者/CLI/基础设施、极客向 | mono-terminal |
| 工作坊、教育手册、公益文化 | paper-craft |

> **刻意没有"拿不准就用 X"的兜底**（ADR-068 D1）：那条兜底正是把风格分布钉死在一处的机制。
> 拿不准时就照 `variants.json` 的前 3 个原样问用户——**让用户选，不是替用户默认**。
