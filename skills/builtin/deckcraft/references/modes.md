# Mode 叙事骨架（怎么论证）— 与视觉风格正交的第二轴

Mode 决定**页序、标题语气、讲稿语域**；视觉风格决定长相；**内容密度是第三条正交轴**，
由 `delivery_purpose`（消费距离，见 `content-engineering.md §五` / `outline-schema.md`）驱动。
**mode 绝不碰密度**——不存在"教学 mode 就该密、发布 mode 就该疏"；投影版通风、讲义版密集
是同一份内容的两个 `delivery_purpose`。三轴独立组合，在第 1 轮 question 里各自推荐并确认（不单独加轮次）。

## Auto-selection

| 信号 | 推荐 mode |
|---|---|
| 汇报/提案/要资源、观众是决策者 | pyramid |
| 讲故事/复盘/品牌、观众要被打动 | narrative |
| 培训/教程/操作指南 | instructional |
| 产品/作品发布、亮点展示 | showcase |
| 情况通报/进展同步、观众要快速掌握 | briefing |

## 五种 mode 速览

### pyramid（金字塔：结论先行）
- 页序：结论页(anchor)先出 → 分论点各页 MECE 展开 → 数据支撑 → 行动项收尾
- 标题语气：**每页标题是断言**（含数字/谓语）。弱 vs 强：「市场概览」❌ →「国内市场年增 23%，窗口在未来两季」✅
- 讲稿语域：论证语气，先亮观点再给证据
- 每个数据必须带对比（同比/环比/竞品/基线），孤数不立

### narrative（叙事：情境→张力→解决）
- 页序：现状情境 → 冲突/张力(breathing 页放大情绪) → 转折方案 → 愿景收尾
- 标题语气：场景化短句，允许悬念（「然后我们发现了问题」）
- 讲稿语域：讲故事节奏，页面留白多、讲稿承载细节

### instructional（教学：认知阶梯）
- 页序：学习目标 → 概念地基 → 分步演示（编号严格）→ 常见错误 → 小结回顾
- 标题语气：动词开头的任务句（「配置你的第一个 agent」）
- 讲稿语域：解释语气，每步预答「学员会在哪卡住」

### showcase（发布：亮点节奏）
- 页序：悬念开场 → 核心亮点逐个满幅呈现（一页一亮点，图/大字优先）→ 规格汇总表 → CTA
- 标题语气：短促有力（≤8 字），数字大写呈现
- 讲稿语域：情绪节奏，长短句交替

### briefing（通报：事实密度）
- 页序：TL;DR 摘要页 → 分域进展（表格/时间线优先）→ 风险与需协调项 → 下步计划
- 标题语气：中性事实句，日期/状态明确
- 讲稿语域：简洁客观，每页 ≤30 秒讲完
